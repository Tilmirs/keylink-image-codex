# 提示词模式与设计流程

大师模式、专业模式使用本指引，并按交付物读取 [design-recipes.md](design-recipes.md)。Codex 负责创作最终提示词，Python 负责准备输入与发送，不额外调用付费文本模型。

## 创作授权与模式边界

**选择大师或专业模式，就是授权 Codex 主动设计。** 把用户提示词当作创作简报：理解希望传达的主题、情绪和用途，然后发展比原稿更完整、更有辨识度的视觉表达。详细输入也可以深化、重组和提升；不要退回“只归整原文”“只补一两项”或逐句扩写。用户尚未锁定的布局、配色、场景、道具、装饰、视觉隐喻和非事实性文案，都可以主动创作，组合成有判断力的方案。

区分明确硬约束和可发展的设计建议：指定逐字文案、品牌与产品事实、参考人物身份、明确说“必须/保持/仅改”的范围属于硬约束；初步描述、示例、偏好与开放方向可以演绎。普通偏好应成为方案的出发点，深化时保持其核心气质；只有确实冲突且会改变成败时才澄清。创作授权不等于换掉用户主题、编造事实，或将局部修改升级为整图重做。

| 模式 | 行为 | 设计主动性 |
| --- | --- | --- |
| 克制 restrained | 恢复三模式引入前的生成与编辑流程 | 不套用大师/专业的设计扩写；新图使用用户视觉描述，编辑提炼本轮修改与保留项，兼容旧会话包装清理。不是后来新增的逐字、空白不动协议。 |
| 大师 master | 从简报自主形成完整视觉方案 | 主动发展概念、空间与背景、构图、光线、色彩、材质、字体与辅助元素，以一套连贯的视觉语言统筹。 |
| 专业 professional | 先让用户从每批 4 张参考图中选择，再进行同等深度的设计 | 用户选图提供灵感方向，Codex 融合参考和素材，重新设计而非复制模板；可发展参考图未覆盖的视觉细节。 |

模式不绑定风格。大师可以大胆、安静、写实、实验或极简；专业模式也可以超出参考图的表面样式，创造适合新主题的表达。

## 收集信息与直接推进

查询模型后，在同一条用户可见的提问中展示三种模式说明，收集模型、输出数量（1～4，默认 1）与模式，邀请用户补充内容/用途与偏好。已有主题直接沿用；“模型名，1 张，专业模式”足够继续。模型和模式独立选择，模式说明只展示一次。同一未提交请求跨轮复用目录及未消耗 token，不因为选模式、选图或修复输入而重复查询。

主体、模型和模式明确后直接开展该模式，不增加固定风格问卷或常规“确认优化稿”。专业模式按 [professional-mode.md](professional-mode.md) 先选图，选择完成后直接设计并生成。仅在主题未知、必需事实缺失、硬约束冲突、编辑范围或图像角色不明时补问；尺寸确认沿用主 Skill。

新图缺省画幅按交付物选择保守尺寸，方向不明则方图；编辑保留底图尺寸。数量、模型、端点和像素尺寸用参数控制，提示词描述画面，不用“8K/UHD”等字样替代真实尺寸，不用四宫格代替四张输出。

## 大师与专业共用的深度设计方法

1. **确定作品要表达什么。** 提炼主体、用途、受众、情绪和最重要的信息。把“高级、好看、有冲击力”转成可见的视觉关系：尺度反差、节奏、材质对照、光影叙事、独特视角或主题隐喻。
2. **先构思，再选择一个强概念。** 可以在内部比较几条方向，选择最适合主题且有新意的一条，写出能统领画面的概念句。不要以常见行业模板代替创意，不必向用户逐一展示内部方案，也不因此增加生图次数。
3. **把概念发展成完整画面。** 联动安排主体、前中后景、背景、光线、配色、材质、字图关系和辅助元素。细节不设机械数量上限；允许主动加入场景、道具、图形、虚构角色或非事实性短文案，只要它们服务作品并符合用户的硬约束。用户要求无字或只显示指定文字时遵守。
4. **让细节形成因果关系。** 写明光从哪里来、照亮什么、如何形成阴影和反射；背景如何衬托主体；辅助图形如何回应轮廓、组织动线或制造节奏；字形如何表达主题。让图像模型看到具体关系，而不是一串“精致、电影感、超高质量”的词。
5. **以正向画面描述为主。** 直接写希望出现的内容和效果。负向词只用于用户明确禁用项、事实/身份保护、局部编辑边界或任务确有必要的排除项；没有必要时可完全省略负向段落。不要默认附带“禁止额外元素、禁止道具、禁止装饰、禁止其他文字”等通用禁令，也不把所有建议写成不可变限制。
6. **做一次创意与执行检查。** 这套方案是否具有可识别的概念？背景、光线和辅助细节是否与它统一？阅读顺序和焦点是否明确？用户锁定内容是否准确？解决冲突和空泛堆词，保留能提升作品的创作细节。大胆与克制由作品需要决定，不能把“删除设计”当作默认优化。

纯摄影、插画、UI、商品和信息图采用各自合适的视觉语言，不强行套海报标题或装饰；局部编辑只在授权区域内进行同样细致的设计。素材用于重新合成并不等于整张图片都不可改变，区分产品/人物身份等锚点与允许重新设计的场景。

## 将设计写成可执行提示词

本机 imagegen 的可借鉴方法是结构化表达、明确图像角色、精确文字和编辑保留项。本 Skill 在大师/专业模式采用用户授权的主动创作幅度，不沿用“详细输入只能归整、不得新增道具或文案”的默认限制。

可按“交付目的与概念 → 场景/背景 → 主体与细节 → 构图与文字 → 光线/颜色/材质 → 必要保留项”组织；复杂方案用短标签或段落，简单画面用自然语言。不要为了短而丢掉关键设计关系，也不要用固定长模板稀释重点。以下维度供内部设计时联动考虑，最终写入真正构成方案的内容：

| 维度 | 写清的设计关系 |
| --- | --- |
| 概念与主体 | 核心视觉隐喻、主体姿态/尺度/视角，主体和环境如何共同表达主题 |
| 场景与背景 | 具体空间或抽象构成、前中后景、地平线/承托面、氛围与纵深，背景如何建立主体轮廓 |
| 构图与阅读 | 焦点、视觉动线、裁切、疏密与留白、对比和节奏；有文字时安排标题、次级文案与图像的关系 |
| 光线与气氛 | 主光方向、软硬与色温，轮廓/环境光的分工，接触阴影、投影和反射如何统一；平面设计可用色面与明暗层次表达 |
| 色彩与材质 | 主辅色与点睛色的面积/对比关系，表面粗糙度、透明度、纸张/织物/金属等触感及与光的互动 |
| 辅助元素 | 可创造主题道具、几何或有机图形、笔触、粒子、图案、角色与环境细节，说明其位置、尺度与主题关系 |
| 文字与字形 | 精确文案用引号隔离，说明字形、字重、字距、层级、换行和图文互动；未锁定且适合广告/封面的文字可主动拟定非事实性标题或副文案 |
| 多图角色 | 按实际传入顺序标明用户素材、编辑底图和风格参考；说明哪些身份/结构要保留、哪些视觉语言要演绎，以及如何协调多图 |

专业模式与大师采用相同的细节深度。参考图是灵感，不是设计上限：分析其空间、字图比例、光线、材质、动势和气质，结合用户主题作新的整合。可以重构版式、发展背景和辅助图形；用户明确“仅参考配色”时仍只在该作用内使用它。

中文请求默认中文，不假设翻译成英文会改善效果。摄影术语用于描述画面；不靠虚构器材参数或印刷精度承诺品质。

## 同一咖啡需求的模式示例

原文：`咖啡海报，标题“慢一点”，棕色系。` 以下是一次设计选择，不是所有咖啡海报的模板。

**克制**：沿旧流程使用这段视觉描述，不追加大师设计方案。若为编辑，则像旧版一样仅组织本次修改、必需文字与保留项。

**大师**：
> 设计一张咖啡主题平面海报，以“把流动的时间停在一杯咖啡里”为概念。咖啡杯以略俯视的近景占据画面视觉重心，杯口的椭圆被提炼成环绕图文的柔弧；蒸汽像缓慢展开的纸带，与标题字距的舒展节奏呼应。背景由温暖奶咖纸面过渡到可可棕的柔软阴影，杯下保留真实接触阴影，侧后方暖光擦亮杯沿与蒸汽，另一侧以低亮度反射呈现陶瓷的细腻表面。标题准确为“慢一点”，用有呼吸感的中文衬线字与杯子形成疏密对照；可配小字“让香气，替时间留白”。以深棕承载阅读、奶咖形成安静空间，一点铜色套印线连接标题与杯口，局部纸纤维和轻微印痕丰富近看的触感。整体松弛而有鲜明图形记忆，远看焦点清楚，近看有材质与字形细节。

**专业**：用户选定图 1 的编辑排版和图 2 的光线后，结合实际素材可写：
> 为用户咖啡产品设计一张棕色系海报，以“香气在纸上留下时间的涟漪”为概念。输入图 1 是用户产品，保留杯形、标志与标签；输入图 2 是排版参考，演绎其大字与小图的尺度反差和非对称留白；输入图 3 是光线参考，借鉴暖侧光、低亮背景与边缘反射，重新组织成适合该产品的场景。让杯口椭圆扩展为背景中的浅棕弧面，前景一条半透明蒸汽形带引导视线进入杯子，再落到标题“慢一点”。标题采用舒展的中文衬线结构，以深棕字和浅纸色形成清楚对比，小字“留一点时间给香气”沿弧线内侧排列。暖光从侧后方照亮杯沿与蒸汽，桌面投影向另一侧舒展，陶瓷高光、纸面颗粒与铜色细线保持统一色温。将参考图的气质转化为这套新的字图与空间关系，画面中的文字使用本方案文案，用户产品保持可辨识。

示例允许新增辅助图形和非事实性文案；若用户已说“只显示标题”，就省略新文案。详细简报同样可以深化材质、光影、图文互动及未锁定的设计选择；“标题必须位于顶部”“仅改标题、其余不变”等明确锁定项始终保留。

## 必须保留与真正需要澄清的内容

- 精确指定文字、标点、姓名、品牌字样、标签、数字、单位和语言逐字保留。用引号区分画面文字与设计说明；不要把说明标签印在图中。
- 不编价格、日期、功效、业务数据、真实身份或背书。可选事实省略，交付必需的缺项才询问。拟定非事实性创意文案不等于获准编造卖点。
- 参考图按顺序说明作用，用户素材身份和产品结构不被网站图替换。不要把参考图上的品牌、可识别人物、标志或文案误认作用户授权内容；仍可自主创作适合本主题的新角色、图形和文案。
- 局部编辑明确“改哪里、保留哪里”；只改标题不重做背景、人物或构图。创作细节围绕允许变化部分展开。
- 有实质冲突时只澄清该冲突，例如“仅显示标题”与“添加副标题”。多参考图尺寸混合时沿用客户端的尺寸检查和确认，不忽略只作风格参考的图片。
- 服务端明确拒绝后停止，不以换词、切换语言或杂志标签隐藏不允许的意图，也不自动提交更多付费尝试。

## 克制模式的旧流程

恢复引入三模式前的行为：新图直接使用用户视觉描述；编辑围绕当前修改、必需画面文字与保留项组织提示词。排除会话记录、日志、工具指令和 Base64；客户端继续解包明确的 JSON、transcript、编辑标题和 tagged context，并按旧逻辑清理外围空白及重复空行。不能宣称编辑正文始终逐字/空白不动。

若旧清理仍拒绝歧义上下文或超过编辑长度限制，按旧流程提炼当前编辑要求，完整保留文案和约束后重试；不能截断或加入大师设计扩写。旧有的参考图压缩、端点回退、尺寸确认、选择令牌、后台任务和结果恢复继续使用当前实现。

## 发送与返回

使用所选 `--prompt-mode` 及最终 `--prompt` 调用 `run`/`start`。有引号、多行、精确文字或 shell 特殊字符时，用文件工具写 UTF-8 文件，再传 `--prompt-file <path>`，不要将视觉文本拼进 shell 代码。大师/专业的最终定稿由客户端精确保留；编辑若仍有会话包装则本地拒绝，由 Codex 整理当前视觉方案。克制与无模式命令走旧清理逻辑。Python 不承担创意改写。

发送前核对主题、文字、参考图作用、保留项、画幅和用户选择，无需常规追加优化稿确认。创作授权不扩大数量、费用或重试次数。返回全部实际图片、数量、模型、尺寸，并逐字附上结果 `sent_prompt`：克制标注“实际使用的提示词（旧流程）”，大师/专业标注“优化后实际使用的提示词”。可简短说明设计概念；专业另列选图来源与用途。

`status`、`last` 使用保存字段，不重写后冒充实际发送稿。只有 `prepared_prompt` 时不能宣称已经发送或成功；旧记录缺失则说明未记录。审美提升要看实际生成图，结构校验和模拟 API 测试不能证明视觉品质。
