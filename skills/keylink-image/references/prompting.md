# 提示词模式与优化流程

在用户选择大师模式或专业模式时读取；具体设计方向见 [design-recipes.md](design-recipes.md)。这些规则由 Codex 执行，不是 Python 的自动改写器，也不额外调用付费文本模型。

## 先收集，再按模式处理

模型查询完成后，同一步收集本次目录里的模型、输出数量与模式，附带邀请用户填写内容/用途、风格；已有信息直接沿用，可选项不用填满。必须在同一条用户可见的提问里展示三种模式及下表说明，只展示一次，不把某个模式绑定某个模型。用户回复选项仍属于同一未提交请求，复用已有目录与未消耗的 token，不因为进入新一轮对话就再查目录。

用户已给出主题后，只回复“模型名，1 张，专业模式”就足够继续：专业模式先按主题检索风格参考供用户选择，大师模式负责整体设计。数量省略按已展示的默认 1 张；模型或模式未选且未明确授权代选时仅补问该选择。只有整个请求都没有主题时才问想画什么，不让用户再次输入已有提示词。

缺省画幅根据明确交付物选择保守尺寸，例如海报竖版、横幅横版，无明显方向则方图；编辑沿用原始底图尺寸。没有指定文案时，大师模式可拟定贴合主题的简短标题/非事实性副标题，专业模式沿用用户文案并用选中的参考图调优版式；用户要求无字或逐字文案时优先服从。缺失的品牌、日期、价格、功效、身份、业务数据等事实不能编造，能省略就省略，必需时只问这个缺项。高分辨率、混合参考尺寸、关键意图冲突仍走主 Skill 的确认流程。专业模式的参考图选择完成后直接进入生成，不增加固定风格问卷。

| 模式 | 处理边界 | 适用做法 |
| --- | --- | --- |
| 克制 restrained | 原文原样发送，适合已有完整提示词 | 不翻译、不润色、不增删、不替换词汇，保留空格、换行、引号；不补缺失的视觉细节。模式/模型/数量等另作参数。边界不明时先问哪段是原文。 |
| 大师 master | 围绕原目标重写，适合让 AI 主导设计 | 先选一个完整视觉概念，再重组主体、布局、配色、材质/光线和文字层级之间的关系；修复冗余与冲突的审美描述。保留硬性要求，仅加入服务目标的细节，不把所有模板字段填满。 |
| 专业 professional | 先选参考图，再调优提示词，适合已有素材但缺少明确视觉方向 | 用网页图片搜索检索 4～8 张候选，展示来源让用户选择；把网站图标记为风格/版式参考，与用户素材一起按客户端压缩策略发送。 |

模式名不代表固定视觉风格。“克制模式”不是极简风，“大师模式”也不默认黑金、奢华、电影风或超模。用户明确的风格优先于模板。继续编辑时沿用用户明确保留的模式，否则补问；不要重新询问已提供的内容。

## 同一需求的三种处理与发送前检查

原文：`咖啡海报，标题“慢一点”，棕色系。`

- **克制**：`咖啡海报，标题“慢一点”，棕色系。` —— 必须逐字相同，不能悄悄增加“高级感”、负面词或副标题。
- **大师**：`设计一张以“放慢节奏”为概念的咖啡海报。右下方放大咖啡杯，以杯口蒸汽的弧线连接左上标题“慢一点”，形成从主体到文字的阅读动线。深咖啡棕承托主体，米白标题区留出呼吸空间，以少量暖棕过渡。用柔和侧光表现杯壁与蒸汽的质感；标题作为唯一文字焦点，保持清晰字形与充足边距。` —— 将同一目标组织为连贯设计，说明各元素为何及如何配合，不能只加“精美、专业、电影级”等形容词。
- **专业**：先检索“咖啡海报 复古平面排版”，让用户选择一张仅借鉴网格、字重和套色关系的参考图，再将“咖啡海报，标题‘慢一点’，棕色系”调优为简洁的最终提示词，并与用户上传的咖啡素材图一起发送。—— 参考图先选择，提示词后定稿，不自动照搬原图内容。

示例说明处理幅度，不默认把所有咖啡海报做成这个布局。发送前按所选模式检查：

1. 克制：最终文本与用户视觉原文完全相同。脚本明确模式下拒绝包装内容不能成为擅自改写理由。
2. 大师：有一个可执行且自洽的视觉方案，体现布局与层级决策。仅改标题等局部编辑的方案必须限定在允许改动范围。
3. 专业：用户明确选择了参考图；最终提示词写清每张图借鉴什么，网站图不覆盖用户素材的身份、产品结构、文字和禁用项。
4. 三种模式均保留精确文案、身份、产品事实、参考图作用、禁用项、模型/数量和已确认尺寸。不要通过删除这些约束制造“区别”。

返回时使用保存的 `sent_prompt`，大师/专业可用一句话说明重组了哪些设计要点；专业模式同时列出用户选择的参考图来源和用途，克制标注“原文未改写”。这是提示词处理方式的真实区别，不保证随机生成的图片一定达到某种审美等级。

## 不可改写的要求

- 原样保留标题、标点、姓名、品牌字样、UI 标签、数字、单位和用户指定的语言；用引号界定画面文字，不能把说明文字当作要印在图中的正文。
- 尊重用户设定的人物身份、外形、服饰、构图与禁用项。参考图逐张指定作用，例如“参考图 1 保留人物，图 2 仅取配色”；不合并、换序、丢图或把参考预览当原图。
- 编辑只优化本轮变化和必要保留条件。“只改标题”不能变成整张海报重设计。即使大师模式也不能重新描述整段会话、擅自换脸或重构不许变的布局。
- 数量、端点、模型和像素尺寸用客户端参数控制。不要为显得专业而加入 2K/4K/8K/UHD、未确认像素尺寸，或把四张独立输出写成四宫格。已确认的画幅可用构图语言表达，不能冲突。
- 实际内容无法满足时直接说明；不要靠同义词、语言切换或杂志标签隐藏不允许的意图。服务端明确拒绝后沿用停止规则，不自动改写重试。

要求冲突时先做一次针对性澄清，而不是替用户选边。例如“必须显示标题”同时“不要文字”，或“只改标题，其余不变”同时要求参考另一张图调色。克制模式保留原文不动；确认的是视觉意图，不是自动同意改写。多参考图仍遵循客户端的尺寸检查；不能仅因某图只参考风格就忽略它，尺寸混合时明确使用底图的输出尺寸并按需确认。

## 大师模式：从概念到平面成稿

用于允许整体设计的请求；局部编辑只在授权区域内应用。海报、封面和图文卡片优先交付正视的平面成品。纯摄影、无字插画、商品白底图不强加标题、网格线或装饰；用户明确要求样机或空间透视时才改变交付形式。

1. **选择概念**：先考虑两到三个真正不同的视觉方向，例如“文字形成主体”“主题物件的隐喻”“图解式叙事”，依据主题关联、识别度和可读性选一个。无需展示内部推演，也不额外生成试验图片。避免只把同一布局换颜色当成不同概念。把选中方向压缩为一句可见关系，如“书页展开成为留给自己的时间空隙”，不要只写“高级、有设计感”。
2. **先排版再装饰**：明确网格、共同对齐线、边距与信息分区；选择对称、非对称、轴线或模块布局中的一种骨架。安排第一眼焦点、第二层信息和阅读终点，通过大小、字重、疏密和留白制造节奏。标题可承担主视觉，与图形形成穿插、呼应或负空间关系，但不损坏指定字形或挡住关键信息。不要每次默认上标题下照片，也不强制固定标题面积。
3. **配置辅助元素**：从主题中提炼一组图形语汇，如咖啡杯口弧线、书页折角、运动轨迹、植物叶脉、科学引线。给每类元素明确位置和功能：分组、连接、指向、建立节奏或解释主题。需要丰富度时使用少量不同尺度的辅助元素，由同一线宽、形状逻辑或色彩统一；不要把所有候选装饰同时放入画面。极简方向可以只用一类甚至不用，局部编辑不能借此新增未授权内容。
4. **让风格控制全局**：按 [design-recipes.md](design-recipes.md) 的场景风格表选择一个主导语言，将它落实到字形气质、网格、色彩比例、图形形态和质感。若混合风格，只融合一个有明确作用的次级特征。科技不自动等于蓝紫霓虹，文化不自动等于水墨山水，女性内容不自动等于粉色，儿童不自动等于贴纸堆满。
5. **写成可执行提示词**：依次说明交付物、核心视觉关系、版式与标题、辅助元素的位置和作用、配色与质感、必要保留项。只保留能影响成品的决定，不把候选方案、设计分析或指令标签印进画面。指定文案逐字保留；不为填版编造英文、编号、日期、价格或数据。
6. **发送前自检**：主题是否一眼可辨？去掉风格形容词后还有具体设计吗？文字与图形是否共享布局逻辑？辅助元素是否能说明功能？缩略图中焦点和标题是否清楚？是否出现无关装饰、伪数据、默认样机或多个风格互相争抢？发现问题先简化最终稿，不增加常规确认轮次。

例如同一咖啡需求的大师稿可以改为：
> 设计正视平面的咖啡海报，以“让阅读节奏慢下来”为概念。采用非对称双栏网格，标题“慢一点”在左栏以清晰厚实的中文衬线字纵向错落排列，通过逐步放宽行间留白表现停顿；三字保持原顺序与完整字形。右下放置俯视咖啡杯，杯口圆形与标题之间留出大块米白负空间。用两段细暖棕弧线呼应杯口，其中一段在标题下方收束阅读动线；右侧窄色块与标题左边界形成疏密对照，不添加文字。深咖啡棕为主，米白承担留白，暖棕少量点缀，轻微纸纤维质感不影响字形。画面只显示“慢一点”，不加副标题、日期、标志或样机。

此例展示字、图、辅助元素共同表达概念，并非后续海报的固定模板。用户指定其他字体、布局或复古风格时沿用其要求。

## 组织方式

先按**交付物 → 风格 → 使用场景**选择 [design-recipes.md](design-recipes.md) 的相应段落。主体清楚而风格未给时，大师按既有流程选择方向，专业模式先检索参考图让用户选择；多个合理的审美方向不需要变成固定问卷。只有它们涉及不同主题、事实或用户互相冲突的要求时才澄清。

专业模式记录所选参考图各自承担的作用；大师模式可使用以下结构，但最终写成易读、紧凑的视觉描述，不必输出字段名或 JSON：

1. 目标交付物与主体：谁/什么、用于哪里，单张成品还是用户明确要求的设计板。
2. 视觉概念与构图：一个中心意象，主体位置、大小、视线或阅读动线，前中后景关系。
3. 风格执行：统一配色、相关材质/笔触、可解释的光源；避免互相冲突的风格堆砌。
4. 文字与层级：列出用户指定或按本模式允许拟定的简短文案，说明主次与位置；非文字型交付物不额外添加口号，用户指定的文字逐字优先。
5. 约束：相关的身份/产品保留、可读性与成品边界。只写最容易出错的几项，不粘贴通用长负面词表。

中文请求默认保持中文；除非用户要求，不翻译成英文来假设“效果更好”。摄影术语按需使用，镜头/光线应服务画面，不能承诺真实摄影器材或印刷级精度。

## 人物措辞与视觉质量

从 editorial-allure-prompting 借鉴正常的摄影/服装语言：用可见的姿态、表情、衣料、光源和空间关系描述想要的效果。词汇是表达工具，**不是违禁词替换表**；不承诺“100% 过审”，不把普通服装或身体词汇一律当作违规词。

| 模糊审美表达 | 在大师/专业模式中的具体化示例 |
| --- | --- |
| 高级、有气场 | 挺括羊毛外套的肩线、平视机位、稳定站姿、背景减少干扰 |
| 有电影感 | 明确主光方向、冷暖环境光关系、适度景深和统一色调 |
| 自然、不像 AI | 保留皮肤细节、自然表情、合理手势与真实环境反光；避免过度磨皮 |
| 有时装质感 | 写清剪裁、面料垂坠、接缝、配饰与衣料反光，而非叠加空泛形容词 |
| 生活感 | 手持视角、日常动作、自然曝光与适量环境细节，不强行套杂志摆拍 |

仅在语义合适且不改变用户目标时做以上具体化。克制模式不做这些处理。人物风格不能自动改变年龄、体型、肤色或身份，也不能把普通日常人像升级成成人化或性化场景。

## 发送与返回

由 Codex 生成最终提示词，使用所选 `--prompt-mode` 与最终 `--prompt` 调用 `run`/`start`。有精确文案、引号、多行或 shell 特殊字符时，用文件工具将最终文本写入本地 UTF-8 文件，改用 `--prompt-file <path>`，防止命令行转义改变文字或执行文本。客户端只发送该文本，不再做语义优化。明确模式的编辑输入若仍含会话包装会在本地拒绝；克制模式请用户提供干净的原文，大师/专业模式只整理当前视觉要求。旧命令不带模式时仍兼容原来的编辑包装清理。

发送前核对题材、指定文字、参考图作用、保留项、画幅和用户选择。无需常规增加一轮“确认优化稿”；按已选模式处理并执行。高分辨率与真正歧义仍需按主 Skill 处理。

返回图像、实际数量、模型与尺寸，并逐字附上结果 JSON 的 `sent_prompt`。后台 `status` 与 `last` 也保存/返回这个字段；不要再次优化后冒充实际发送稿。克制模式标注“原文，未改写”，大师/专业模式标注“优化后实际使用的提示词”；专业模式另外列出用户选择的参考图 URL 和用途。只有 `prepared_prompt` 的任务刚启动，不能宣称请求成功。旧记录缺失时明确说明未记录。

来源与许可见 [sources.md](sources.md)。上游是设计参考，不控制本 Skill 的端点、授权、账号配置和重试行为。
