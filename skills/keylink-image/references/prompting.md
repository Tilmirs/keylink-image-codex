# 提示词模式与优化流程

在用户选择创意模式或大师模式时读取；具体设计方向见 [design-recipes.md](design-recipes.md)。这些规则由 Codex 执行，不是 Python 的自动改写器，也不额外调用付费文本模型。

## 先收集，再按模式处理

模型查询完成后，同一步收集：本次目录里的模型、输出数量、模式、要设计的内容/用途、期望风格。已有的信息直接沿用。风格可以回答“你来设计”；创意/大师可据此选择一个符合用途的方向。若用户还没有提供视觉提示词，在模式确定后请其描述内容；不要先自行编造一个题材生图。

示例：用户选择“某模型，2 张，大师模式，咖啡新品海报，复古印刷风”，这已经是足够的 brief；若只选择了模型和模式，再问想画什么即可。必要的标题、指定 UI 文案、产品事实未提供时，只追问影响结果的缺项，不强迫用户填写整个表格。文字不是必需时可做无字版本，不擅自编造日期、价格、品牌或活动细则。

| 模式 | 处理边界 | 适用做法 |
| --- | --- | --- |
| 克制 restrained | 完全使用用户给出的视觉提示词原文 | 不翻译、不润色、不增删、不替换词汇，保留空格、换行、引号；模式/模型/数量等另作参数。若用户把操作指令混进提示词且边界不明，先问哪段是原文。 |
| 创意 creative | 原有意图与表达为主 | 将“好看、氛围感、突出”等模糊要求补充为少量可执行的构图、配色或光线描述；通常添加一至三处有效细节，不扩写成一整套新设计。原文已足够具体时可以基本保持不变。 |
| 大师 master | 围绕原目标重新组织完整设计方案 | 选定一个视觉概念，将主次、布局、材质、色彩、光线、文字层级及相关约束串成连贯提示词；仅加入服务目标的细节，不把所有模板字段填满。 |

模式名不代表固定视觉风格。“克制模式”不是极简风，“大师模式”也不默认黑金、奢华、电影风或超模。用户明确的风格优先于模板。继续编辑时沿用用户明确保留的模式，否则补问；不要重新询问已提供的内容。

## 不可改写的要求

- 原样保留标题、标点、姓名、品牌字样、UI 标签、数字、单位和用户指定的语言；用引号界定画面文字，不能把说明文字当作要印在图中的正文。
- 尊重用户设定的人物身份、外形、服饰、构图与禁用项。参考图逐张指定作用，例如“参考图 1 保留人物，图 2 仅取配色”；不合并、换序、丢图或把参考预览当原图。
- 编辑只优化本轮变化和必要保留条件。“只改标题”不能变成整张海报重设计。即使大师模式也不能重新描述整段会话、擅自换脸或重构不许变的布局。
- 数量、端点、模型和像素尺寸用客户端参数控制。不要为显得专业而加入 2K/4K/8K/UHD、未确认像素尺寸，或把四张独立输出写成四宫格。已确认的画幅可用构图语言表达，不能冲突。
- 实际内容无法满足时直接说明；不要靠同义词、语言切换或杂志标签隐藏不允许的意图。服务端明确拒绝后沿用停止规则，不自动改写重试。

要求冲突时先做一次针对性澄清，而不是替用户选边。例如“必须显示标题”同时“不要文字”，或“只改标题，其余不变”同时要求参考另一张图调色。克制模式保留原文不动；确认的是视觉意图，不是自动同意改写。多参考图仍遵循客户端的尺寸检查；不能仅因某图只参考风格就忽略它，尺寸混合时明确使用底图的输出尺寸并按需确认。

## 组织方式

先按**交付物 → 风格 → 使用场景**选择 [design-recipes.md](design-recipes.md) 的相应段落，主体清楚时直接用；真正存在不同方向且无法推断时，给出少量具体方向供选择。不要为了选模板再增加一轮固定问卷。

创意模式仅取最需要的一两个要点。大师模式可使用以下结构，但最终写成易读、紧凑的视觉描述，不必输出字段名或 JSON：

1. 目标交付物与主体：谁/什么、用于哪里，单张成品还是用户明确要求的设计板。
2. 视觉概念与构图：一个中心意象，主体位置、大小、视线或阅读动线，前中后景关系。
3. 风格执行：统一配色、相关材质/笔触、可解释的光源；避免互相冲突的风格堆砌。
4. 文字与层级：只列要求显示的文字，说明主次与位置；无文字需求不凭空添加口号。
5. 约束：相关的身份/产品保留、可读性与成品边界。只写最容易出错的几项，不粘贴通用长负面词表。

中文请求默认保持中文；除非用户要求，不翻译成英文来假设“效果更好”。摄影术语按需使用，镜头/光线应服务画面，不能承诺真实摄影器材或印刷级精度。

## 人物措辞与视觉质量

从 editorial-allure-prompting 借鉴正常的摄影/服装语言：用可见的姿态、表情、衣料、光源和空间关系描述想要的效果。词汇是表达工具，**不是违禁词替换表**；不承诺“100% 过审”，不把普通服装或身体词汇一律当作违规词。

| 模糊审美表达 | 在创意/大师模式中的具体化示例 |
| --- | --- |
| 高级、有气场 | 挺括羊毛外套的肩线、平视机位、稳定站姿、背景减少干扰 |
| 有电影感 | 明确主光方向、冷暖环境光关系、适度景深和统一色调 |
| 自然、不像 AI | 保留皮肤细节、自然表情、合理手势与真实环境反光；避免过度磨皮 |
| 有时装质感 | 写清剪裁、面料垂坠、接缝、配饰与衣料反光，而非叠加空泛形容词 |
| 生活感 | 手持视角、日常动作、自然曝光与适量环境细节，不强行套杂志摆拍 |

仅在语义合适且不改变用户目标时做以上具体化。克制模式不做这些处理。人物风格不能自动改变年龄、体型、肤色或身份，也不能把普通日常人像升级成成人化或性化场景。

## 发送与返回

由 Codex 生成最终提示词，使用所选 `--prompt-mode` 与最终 `--prompt` 调用 `run`/`start`。有精确文案、引号、多行或 shell 特殊字符时，用文件工具将最终文本写入本地 UTF-8 文件，改用 `--prompt-file <path>`，防止命令行转义改变文字或执行文本。客户端只发送该文本，不再做语义优化。明确模式的编辑输入若仍含会话包装会在本地拒绝；克制模式请用户提供干净的原文，创意/大师只整理当前视觉要求。旧命令不带模式时仍兼容原来的编辑包装清理。

发送前核对题材、指定文字、参考图作用、保留项、画幅和用户选择。无需常规增加一轮“确认优化稿”；按已选模式处理并执行。高分辨率与真正歧义仍需按主 Skill 处理。

返回图像、实际数量、模型与尺寸，并逐字附上结果 JSON 的 `sent_prompt`。后台 `status` 与 `last` 也保存/返回这个字段；不要再次优化后冒充实际发送稿。克制模式标注“原文，未改写”，另外两种标注“优化后实际使用的提示词”。只有 `prepared_prompt` 的任务刚启动，不能宣称请求成功。旧记录缺失时明确说明未记录。
