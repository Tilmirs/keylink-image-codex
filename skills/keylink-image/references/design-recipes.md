# 按设计方向选择提示词要点

配合 [prompting.md](prompting.md) 使用，只读取当前交付物相关段落。专业模式获得主动设计授权：把这些维度发展成有辨识度的方案，详细简报也可深化未锁定选择。细节围绕一个强概念联动，不设“只补几项”的限额；示例提供创作深度，不规定每次的颜色、布局或风格。

## 自媒体：小红书、抖音、视频号、公众号、B 站、知乎

自媒体封面、笔记图、正文配图、教程卡片、视频插图和人物 IP 内容，读取 [social-media.md](social-media.md)。按平台与交付物统筹手机阅读层级、视觉叙事、文字密度或字幕空间。探索沿用旧生成与编辑流程，专业先选每批 4 张的风格参考再深度设计。该参考也包含画幅、裁切和多图规则。

## 海报、封面、字体设计

先提炼主题的视觉隐喻，再统筹字图比例、空间、阅读动线与情绪。可以重组未锁定的布局，采用大尺度裁切、非对称平衡、图像与字形互动、层叠空间或动态轴线；让版式服务概念，不把海报固定为“上方标题、下方产品”。有文字时深入设计字体与信息层级，无字作品则以图形或场景承担叙事。

- 常规海报：围绕主题主动发展主视觉、背景、光影、色彩与材质，让标题与图像形成独特关系。可设计辅助图形、主题道具和非事实性副文案，建立节奏、空间和记忆点；精确标题和用户锁定项保留，价格、日期、功效等事实不编造。用户说无字或仅显示指定文字时遵守。
- 概念字体：标题字形可以承担主视觉，以字重、字距、负空间或形象与字的互动表达主题，始终保证原文字形可辨。用户要单张成品时不要生成 moodboard、样机或多方案网格。
- 运动商业视觉：姿态、器材和空间关系应合理，让运动员或商品成为焦点；强光影与运动动线不应变成杂乱拼贴。
- 水墨/文化：用轮廓、墨色扩散、留白连接叙事元素，不默认加入无关山水或特效；准确性重要时保留时代和服饰体系。

例如用户原文为“咖啡海报，标题‘慢一点’，复古印刷风，棕色系”：

专业示例（假设用户素材为图 1，所选风格参考为图 2）：
> 以“让香气在纸上慢慢展开”为概念，设计一张棕色系复古印刷咖啡海报。保留输入图 1 的杯形与标签，输入图 2 提供标题尺度和纸面套色的灵感，重构为杯口椭圆与中文字形相互呼应的版式。标题“慢一点”以宽舒的深棕衬线字成为主视觉，杯子略偏离中轴，让蒸汽沿弧形负空间穿过字间而不损害辨认。奶咖背景上的柔软斜影建立纵深，暖侧光照亮杯沿，哑光陶瓷与粗纤维纸面形成触感对照；铜棕线条和局部错版印痕呼应杯口轮廓。小字“把片刻，留给香气”作为次级节奏，与主标题保留清楚的尺度差。

完整简报也可以深化字形、光影、材质和未锁定的布局选择；精确文案与明确保留项仍优先。以上是选图后的一次创作演绎，不是默认模板；用户要求只显示标题时省略示例中的副文案。

这些专业模式定稿示例均在用户选图后使用；实际提示词还须按输入顺序说明所选参考的作用，并遵守用户授权的设计范围。编辑海报只改标题时，提示词应类似“仅将标题改为‘慢一点’，原字体位置、其余文案、背景和产品保持不变”，不能套用上面的重新设计稿。

## 场景与风格：按主题选择设计语言

专业将所选图的视觉语言转译为适合本主题的新方案，同样可以深入创造背景、光线和辅助元素；探索沿旧流程，不套用本配方。下表是灵感词汇，可以跨方向组合、变形和发展，不按行业分配固定模板。事实、身份和明确保留范围依旧准确。

| 场景／主题 | 可选主导语言与排版 | 有作用的辅助元素 | 使用边界 |
| --- | --- | --- | --- |
| 科技工具、商业解释、效率 | 瑞士现代主义／信息设计；非对称网格、清晰无衬线层级、单一强调色 | 模块边界、连接线、与内容对应的简化图标，组织因果或流程 | 不加无意义代码、悬浮数据与默认霓虹 |
| 实验艺术、青年文化、音乐 | 实验字体／粗野主义平面；大字裁切与强对比块面、受控错位 | 重复线条、节拍点阵、主题相关的撕纸形态，建立节奏 | 精确标题仍完整可辨，不能靠杂乱或乱码冒充实验 |
| 展览、建筑、文化出版 | 编辑设计／国际主义；轴线与宽边距、图像和标题的尺度对照 | 图注引线、细分隔线、建筑轮廓提炼，连接信息 | 无资料时不编展期、策展人或作品编号 |
| 咖啡、书店、复古生活 | 复古平版印刷／独立刊物；衬线标题、非对称图文与纸色留白 | 杯口弧线、书页折角、少量套色图形，呼应主题物件 | 不默认咖啡色滤镜、旧报纸堆叠或虚构店名 |
| 旅行、生活记录、个人随笔 | 编辑拼贴／手账；照片与手绘局部形成轻重节奏 | 路径线、与地点有关的小图、纸片边缘，组织观察顺序 | 不虚构路线、坐标或票据；不覆盖真实人物与地标 |
| 儿童科普、亲子、启蒙 | 几何插画／亲和图解；大图形、短标签、明确分组 | 步骤连接、局部放大框、与知识点对应的角色或图标 | 不用无关贴纸塞满；知识、数字与标签须有依据 |
| 教程、清单、知识卡片 | 模块信息设计；按内容选择流程、对比或分组骨架 | 有语义的箭头、分区线、步骤图标，解释真实关系 | 不为了整齐新增步骤、结论或数据 |
| 运动、户外、赛事主题 | 动态字体／构成主义；对角轴线、强字重与方向对比 | 与动作一致的轨迹、局部切片、方向条，强化动势 | 不遮挡肢体与器材；赛事事实不得编造 |
| 自然、环保、植物 | 植物版画／有机现代主义；疏朗网格与不规则有机形对照 | 叶脉、轮廓线、种子图形，表达生长或连接 | 不将所有主题染绿，不添加未经支持的环保认证 |
| 传统文化、节令、地域主题 | 当代东方平面／木刻版画；汉字结构与留白、有限套色 | 来自具体器物或纹样的边饰、印痕与线形，建立文化关联 | 不混用朝代、虚构印章或把无关山水作通用背景 |
| 美妆、时装、人物栏目 | 时装编辑／精简字体；标题与人物轮廓呼应、克制色块 | 细框、局部材质切片、栏目分隔，建立图文秩序 | 不改变人物身份和产品结构；不自动加入奢华黑金 |
| 餐饮、产品上新、电商 | 大字商品平面／现代波普；产品轮廓与标题形成大小对照 | 原料剪影、口味色块、相关形状重复，解释产品特征 | 原料与卖点来自用户；不编价格、销量或功效 |

辅助元素既可以组织阅读、解释信息，也可以建立情绪、节奏、材质层次与视觉惊喜。可主动发展抽象图形、主题道具、纹理和空间细节，让它们与主概念统一；不必每一项都承担信息功能。无字摄影、白底商品和保留原布局的编辑按各自交付范围设计。

## UI/UX、网页、App、仪表盘

这是位图界面设计，不宣称交付可交互页面或生产代码。先定平台、页面任务和主要操作；手机单屏、桌面页面、社交截图与仪表盘不能混用骨架。专业模式缺省平台时按用途推断（App 通常手机，网页通常桌面），泛指 UI 则选一个合理的单屏平台并告知；不用为每个可补设计项再次提问。精确复刻或互相冲突的平台要求才需澄清，探索模式不添加未提供的平台描述。

- 结构：说明导航、内容区、主操作和必要辅助区的位置，控制信息密度；真正的仪表盘才加入相关数据组件。
- 视觉系统：统一间距节奏、字体层级、控件圆角、图标粗细和强调色；为正文和按钮保持足够对比。只突出一个主要操作，其余操作退为次级。
- 可读性：保留用户指定的按钮/标签文案，不生成乱码和无意义占位段落；不擅自编造业务数据、价格或账号信息。允许示意数据时简短且一致。
- 交付形式：用户要平面单屏时不加倾斜透视、设备外壳或多页拼贴；用户要求设备样机时才加入这些元素。界面层不遮挡重要人物或内容。

专业定稿示例（选图后发展移动端阅读首页，暖白风格，指定标题和主按钮）：
> 为移动端阅读 App 设计一张平面首页，以“书页像窗一样打开”为概念。暖白底与深灰文字建立安静阅读氛围，森林绿用于主操作，浅杏色用于栏目背景。标题准确为“继续阅读”，下方阅读卡片以大面积书页折角和柔和投影形成触感，书籍封面采用原创抽象图形；主按钮准确为“开始阅读”，与卡片共用一条清楚的对齐轴线。“书架”“发现”以次级导航文字形成轻量入口，间距、圆角和图标线宽保持一致，触控区域充足。纸面层次、细线与局部绿色弧形呼应翻页动作，重点内容醒目，界面像完成的产品而不是通用组件拼贴。交付一张完整平面首页，数据与具体书名等待用户提供。

## 人物摄影、日常抓拍、角色设定

先分清写实人像、日常记录、时装摄影、插画角色、设定表或收藏玩具。画面用途决定摄影语言，不把所有人物都处理成杂志超模。

- 写实肖像：确定景别、机位、视线与表情、主体和背景距离；选一个可信主光源，写清相关面料与自然皮肤纹理。不靠过度磨皮、液态高光或不合理浅景深制造“高级感”。
- 时装摄影：用衣料垂坠、剪裁线条、姿态与背景材质建立秩序。可借鉴侧光、轮廓光和明暗对比，但不为绕过内容审核而使用遮挡或暗语。
- 日常抓拍：用真实动作、相机距离、自然曝光和少量生活细节建立临场感；手持透视、运动模糊和环境杂乱应适量且合理，不强行加入胶片、棚拍或高级时装标签。
- 人物参考：保留脸型、发型、服装标志及用户指定身份特征；仅换背景或衣服时不重塑身材与五官。多人物要写清各自位置和动作，不把两人合成一人。
- 角色设定：身份锚点、比例、服装、配色与关键配件保持一致；用户要求多视图/动作表时才写面板数量与布局，不能用它代替多张独立输出。
- 玩具/3D：先锁身份识别点，再确定风格化比例、哑光树脂/织物等材质与棚拍光线；不把材质细节写成未经确认的 8K 分辨率要求。

专业定稿示例（选图后发展“成年女性，黑西装，灰背景，杂志风”）：
> 成年女性的黑西装杂志肖像，以“柔软空间中的利落轮廓”为视觉概念。采用略低机位的半身构图，肩线与面部转向形成轻微反向张力，手自然搭在腰际，神情平静而坚定。灰色背景由细腻石灰墙面和一片弧形浅灰板组成，侧前方大面积柔光塑造面部，侧后方窄光勾出西装肩部，背景弧板接收拉长的渐变阴影。黑色羊毛面料保留纹理、折线和轻微织物反射，肤质自然，暖灰与冷灰在空间中形成微妙分离；画面以比例、光影与触感建立时装编辑气质。

## 商品、品牌与电商

区分用户产品锚点与网站风格参考：用户产品的形状、包装文字、标志及明确材质保持准确；网站图提供视觉语言，其产品不是要复制的主体。主动设计承托空间、背景、主光与环境反射、接触阴影、主题道具和图形，既展示产品，也表达品牌情绪与概念。概念产品设计按用户允许范围探索造型；卖点、价格与功效须有依据，非事实性创意文案可以拟定。品牌板按用户交付范围制作，多触点保持统一视觉语言。

## 信息图、科普与出版物

先定信息顺序和必要模块，再分配标签、图形与留白。模块数随内容而定，不把长段正文强塞成小字；标题、单位、数值和图表关系必须准确，缺数据先询问。要求单张科普海报时保持一个视觉中心，不自动扩成百科板。位图图表不代表数据已核验或能编辑。

## 插画、场景与空间

插画用明确的主体动作、构图、媒介/笔触与统一配色；不只堆“水彩、国风、未来感”等风格词。叙事场景用人物、地点、时间与一个可见事件建立故事。空间设计先定功能、视点、尺度、材质与光源；除非用户要求概念变形，保持合理透视与结构。历史准确性有要求时不要混合朝代器物。
